# TD 打卡（Android）

从「高级功能 → TD 打卡」进入，选择同一校区的入口和出口、轮数及等待间隔，点击开始。

入口和出口直接使用内置的 `image2.jpg`，取自提供的 TD 文件夹，与原配置一致。学号使用当前账号，校园卡号留空时按学号转换为十六进制。

手机连接校园网后执行。开放时间为北京时间 07:30–10:00、11:30–14:00、15:30–20:00。

入口、出口按顺序执行，页面显示轮次及结果。点击「停止任务」结束队列；切换或退出账号也会停止当前队列。记录和照片提交成功后发送通知。

主要实现：`shared/.../td/TdProtocol.kt`、`composeApp/src/androidMain/.../td/`。内置图片：`androidApp/src/main/assets/td/image2.jpg`。
