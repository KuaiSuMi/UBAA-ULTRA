# 健康云（Android）

「高级功能 → 健康云」提供 TD 次数与体测成绩。连接校园网后，进入页面即自动查询，返回前台时重新获取，也可点击「刷新」。查询复用当前账号的北航统一认证会话。

TD 页面同时显示健康云的最近学期统计，健康云页面显示各学期统计与来源次数。这里展示校方统计值，不累计本地提交次数。体育部说明 TD 统计每 24 小时更新一次，页面分别显示学期和本次获取时间。

体测成绩入口和可查询年度从健康云页面读取，可按年份切换成绩。保留成绩表的项目、学年、成绩、得分和合计等原始字段。合并单元格展开后按原表顺序显示，宽表可横向滑动。切换账号后重新查询所选账号的数据。

## 查询流程

1. 使用已保存的 SSO Cookie 访问 `http://10.212.28.38/index.php?schoolno=10006`，建立学校及用户上下文。
2. 查询 `main.php?module=stu&title=stu_sun_score`，读取 TD 汇总表。
3. 从校园网页面导航查找体测成绩链接，读取成绩表。

HTML 使用项目已有的 Jsoup 依赖解析。请求失败或返回登录页时显示查询错误，不将其计为零次。

接口参考：[健康云 TD 查询实现](https://github.com/y38501148-max/muztools/blob/main/backend/muztool/td.py)。更新频率来源：[北航体育部查询说明](https://tyb.buaa.edu.cn/info/1035/4279.htm)。
