# 全校课程（Android）

从“课表 → 全校课程查询”或“高级功能 → 全校课程”进入。

- 按课程名、课程号或课程负责人姓名搜索。
- 可选择学期，也可查看全部学期。
- 每页显示 20 条，可翻页查看完整结果。
- 课程卡片显示课程号、中英文名称、院系、学分、学时、课程负责人、类别、考核方式、授课语言和培养层次。

课程库来自[本研系统教学大纲查询](https://byxt.buaa.edu.cn/jwapp/sys/kcdgglbuaa/*default/index.do#/jxdgcx)，包含未选修课程及历年课程。

## 上课时间与回放

点击“全校排课时间与回放”，或课程卡片上的“上课时间与回放”，进入[智学北航课程中心](https://classroom.msa.buaa.edu.cn/courseCenter)。课程卡片会自动填入课程名称；按学期、教师选择对应教学班后，可查看每次课的日期、起止时间、教室和回放状态。

主页今日课程和个人课表详情也提供“课程回放”入口。已有录像的课次显示“观看回放”，进入后可选择教师、课件等视角或视频片段，拖动播放进度、横屏全屏观看。切换到后台会暂停并释放播放器，返回后从原位置继续。

回放按当前账号的校方观看权限加载。未选课程可联系任课教师添加旁听生。排课变动和新录像的同步时间以智学北航为准，见[教务部说明](https://jiaowu.buaa.edu.cn/index/byxt.htm)。

查询复用当前账号的直连或 WebVPN 会话。后台会话需要验证码时，在主页点击“统一认证需要验证”完成验证后继续查询。

回放访问时自动恢复过期会话，认证跳转使用 HTTPS。统一认证要求验证码时，可在回放页面直接完成验证，随后继续加载当前课程或视频。
